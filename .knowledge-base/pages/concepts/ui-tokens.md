# Ui Tokens

Canonical UI tokens and clinical workspace character for X-INSIGHT.

## Identity and theme

Product name is X-INSIGHT; the principal wordmark uses INSIGHT in uppercase (docs/dev/ui-context.md, Section: Product Identity and Branding). Light theme is the only approved theme; no dark-mode toggle exists until an approved dark palette and accessibility review exist (docs/dev/ui-context.md, Section: Theme-mode status). Avoid playful illustration, gradients, glassmorphism, neon, marketing typography, and consumer-wellness styling (docs/dev/ui-context.md, Section: Current Design Character).

## Tokens

Canonical tokens use `--primary: #0A9E8F`, ink `#111827`, canvas white, plus urgent/warning/normal/follow-up/info states (docs/dev/ui-context.md, Section: Canonical Color System). Teal #0A9E8F on white is ~3.33:1 contrast, suitable only for non-text boundaries or large/bold text, not small body copy (docs/dev/ui-context.md, Section: Verified contrast constraint). Dense clinical workspaces use compact type, 8px rhythm, 8–12px card radii, restrained shadows, and `prefers-reduced-motion` support (docs/dev/ui-context.md, Section: Typography).
