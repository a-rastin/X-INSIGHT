# Assessment Workflow

Synthesis — from first presentation through a documented person-centered plan.

## Evaluate

Start with the comprehensive Statement 1 assessment: presenting reason, goals, psychiatric/trauma history, substance use, treatment history, physical health, psychosocial/cultural factors, MSE with cognition, and suicide/aggression risk (docs/medical-docs/guideline/STATEMENT-01.md, Section: STATEMENT 1). Apply the six-requirement DSM-5-TR diagnostic guideline — characteristic symptoms, functional decline, 6-month course, and mood/substance/developmental exclusions (docs/medical-docs/schizophrenia-criteria.md, Section: Required criteria). See [schizophrenia](../entities/schizophrenia.md).

## Measure

Include a quantitative symptom/function measure at initial evaluation to set baselines and track response (docs/medical-docs/guideline/STATEMENT-02.md, Section: STATEMENT 2). Use PANSS item and subscale scores rather than the total alone (docs/medical-docs/PANSS.md, Section: Interpretation) and C-SSRS severity/behavior levels with high-risk flags for recent level 4–5 ideation or behavior (docs/medical-docs/CSSRS.md, Section: Interpretation). Details: [PANSS](../entities/panss.md), [C-SSRS](../entities/c-ssrs.md).

## Plan

Every patient has a documented comprehensive person-centered plan including evidence-based nonpharmacological and pharmacological treatments (docs/medical-docs/guideline/STATEMENT-03.md, Section: STATEMENT 3). Build it over several visits and revise iteratively for response, tolerability, adherence, insight, and diagnosis change; record rationale plus specific changes (docs/medical-docs/guideline/STATEMENT-03.md, Section: Implementation). In X-INSIGHT terms this maps to the register → assess → review AI proposal → finalize and sign flow (docs/dev/user-requirements.md, Section: X-INSIGHT).

Related: [guideline statements](guideline-statements.md), [reasoning pipeline](reasoning-pipeline.md).
